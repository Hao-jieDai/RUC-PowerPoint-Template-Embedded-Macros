RUC PowerPoint Template (Embedded Macros)

适用于 Windows 版 Microsoft PowerPoint 的人大风格可编辑模板，内置章节导航、圆点跳转、目录更新和页码刷新功能。

下载模板 · 查看 Releases：https://github.com/Hao-jieDai/RUC-PowerPoint-Template-Embedded-Macros/releases

预览图：预览.png

1. 人大模板来源

本项目根据 RUC Beamer Theme（https://www.overleaf.com/latex/templates/ruc-beamer-theme/ssryphkjpyjt） 改编，将原 LaTeX 模板的配色、校徽、背景与版式转为可编辑的 PowerPoint，并加入内置 VBA 宏。

- 原模板作者：Wenquan Wu。
- 原模板仓库：GohUnTsuan/RUC-Beamer-Theme（https://github.com/GohUnTsuan/RUC-Beamer-Theme）。
- 原模板许可：CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）。分享改编版本时，请保留来源、许可及改编说明。
- 原项目亦致谢了 Jiayi Weng 的 THU-Beamer-Theme（https://github.com/Trinkle23897/THU-Beamer-Theme）。

本版保留 16 页示例、母版和可复用版式。中文使用楷体，英文和数字使用 Times New Roman；字号为整数，段落采用 1.5 倍行距、零缩进、零段前段后间距。

2. 发布包的内容

人大PPT模板.pptm：编辑底稿，包含宏与“人大模板”选项卡；用于制作报告和更新导航、目录、页脚及页码。
人大PPT模板_示例.pptx：通用展示示例，可直接编辑或放映；保留已有的圆点、目录跳转和页码，不含宏，不支持自动重新统计。
人大模板_宏源码.bas：内置宏的完整 VBA 源码，供查看和修改。
预览.png：PowerPoint 中的模板预览，并突出显示“人大模板”选项卡的三个按钮。
README.md、README.txt：同一份使用说明；前者用于 GitHub 页面展示，后者方便离线阅读。

3. 如何使用

1. 保留原始 .pptm 底稿不变，先复制一份副本，例如“我的报告.pptm”。
2. 用 Windows 版 Microsoft PowerPoint 打开副本；确认文件来源可信后，按提示启用宏。
3. 修改第一页封面的报告题目、姓名和学院，编辑各页内容，并按需要增加、删除或移动幻灯片。
4. 用 PowerPoint 左侧缩略图中的“节”组织章节。右键节名称可以重命名；右键缩略图或使用“开始 → 节”可以添加节。
5. 按下节说明点击对应按钮，完成更新，再保存 .pptm 编辑稿。
6. 展示前，另存一份 .pptx 文件带去教室或其他电脑放映。后续继续编辑时使用 .pptm，更新后重新导出 .pptx。

已保存的圆点和目录链接属于普通 PowerPoint 内部链接，放映电脑无需启用宏即可点击跳转。但在 .pptx 中继续增删页面后，圆点数量和总页数不会重新计算。

宏通过点击按钮执行，不会在每次编辑后自动运行。当前页码使用 PowerPoint 原生字段，总页数由宏更新。默认所有幻灯片都计入总页数；名为“封面与目录”和“结束页”的节不显示在顶部导航中。

4. “人大模板”的三个按钮

① 刷新导航和页码

常规编辑完成后使用此按钮：

- 修改封面信息后：将第一页封面的报告题目、姓名和学院同步到所有页脚。
- 新增、删除或移动页面后：重新统计各节页面数量，更新顶部圆点、当前页高亮、跳转目标及“当前页 / 总页数”。
- 修改节名称后：更新顶部章节标题。

请保留封面为第一页，并直接修改现有题目、姓名和学院文本框中的文字，以便宏识别。普通刷新保留手工编辑的目录文字和位置，只更新其对应的跳转链接。

② 从节重新生成目录

需要修改或更新目录时，先在左侧缩略图中修改节名称或调整节，再点击此按钮并确认。

此操作会根据当前节的名称和顺序，重新生成总目录及章节过渡页中的目录条目，并同时刷新顶部导航、页脚和页码。章节过渡页会突出显示当前章节。

确认后，由模板管理的目录条目的手工文字、位置和格式会被重新生成的内容替换；自行新增的普通文本框会保留。若要保留手工改写的目录，请使用“刷新导航和页码”。

③ 使用说明

显示常用操作提示，方便编辑时快速查阅。完整说明以本 README 为准。

改封面后，统一更新所有页脚：刷新导航和页码
增删或移动页面后，更新圆点和页码：刷新导航和页码
改节名称后，只更新顶部章节标题：刷新导航和页码
改节名称或数量后，重新生成目录：从节重新生成目录
查看操作提示：使用说明

5. 宏提示和源码

启用宏

.pptm 中已经包含宏，无需单独导入源码。若 PowerPoint 提示宏被禁用，请先确认文件来源，再按所在学校或单位的安全要求允许这份文件运行。

网络下载的文件可能被 Office 阻止运行宏。处理方法见微软的网络文件宏阻止说明（https://learn.microsoft.com/en-us/microsoft-365-apps/security/internet-macros-blocked）。无需降低全局宏安全等级，也无需开启“信任对 VBA 工程对象模型的访问”。

如果电脑的管理策略不允许宏，仍可使用 .pptx 放映，但不能在该电脑上重新计算导航和总页数。

保存与展示

编辑稿请保存为 .pptm。另存为 .pptx 会移除 VBA 宏；PowerPoint 可能保留“人大模板”选项卡，但其中的宏按钮将不可用，已保存的放映跳转不受影响。本包提供的 .pptx 示例已移除该选项卡。

查看源码

可以在 PowerPoint 按 Alt+F11 查看文件内的 VBA，也可以阅读随附的 人大模板_宏源码.bas。源码文件使用 UTF-8 编码，便于在 GitHub 和文本编辑器中查看；如果需要通过 VBA 编辑器重新导入，请先将源码另存为简体中文 Windows 的 GBK 编码。

代码只在点击按钮时执行，不访问网络、不启动外部程序。所有幻灯片的备注区保持为空，必要说明均集中在 README 中。
